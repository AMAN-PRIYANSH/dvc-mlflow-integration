What each metric means

TP = malignant tumours correctly flagged, TN = benign correctly cleared, FP = benign wrongly flagged, FN = malignant missed.

Accuracy
(TP + TN) / all patients. How many predictions were right overall.
Precision
TP / (TP + FP). When the model says “malignant”, how often it is right.
Recall
TP / (TP + FN). Also called sensitivity. Of the real malignant tumours, how many the model caught.
F1-score
2 × Precision × Recall / (Precision + Recall). One number that balances precision and recall.
Specificity
TN / (TN + FP). Of the real benign tumours, how many the model correctly cleared.
ROC-AUC
Area under the ROC curve. The ROC curve plots recall against the false positive rate for every possible threshold. 1.0 is perfect, 0.5 is random guessing.

Reproduce it

python run_all.py                  # whole pipeline: DVC versions, MLflow runs, this report
python train.py --version v2.0     # train again on one data version
streamlit run app.py               # the GUI: pick a data version, train, see the metrics
git checkout v1.0 && dvc checkout  # bring back data version v1.0 in the folder
git checkout main && dvc checkout  # and return to the newest version
